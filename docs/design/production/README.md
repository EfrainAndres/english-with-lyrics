# Production — Phase 0 Ebook PDF

This folder contains the production-ready HTML and CSS for the Sing Pronounce
Repeat / English with Lyrics Phase 0 ebook.

## Status

**PRODUCTION DRAFT — pending manual QA approval before public delivery.**

## Files

| File | Purpose |
|---|---|
| `phase-0-ebook.html` | 18-page production ebook (full learner content) |
| `phase-0-ebook.css` | Production design system (derived from prototype) |
| `phase-0-ebook-production-draft.pdf` | Exported draft PDF for review (generated by export script) |
| `README.md` | This file |

## How to open locally

```
open docs/design/production/phase-0-ebook.html
```

Or drag the file into any modern browser window.

## How to export the PDF

Run from the repository root:

```bash
bash scripts/export-ebook-pdf.sh
```

Requires Python 3 and Google Chrome or Chromium installed.

Output: `docs/design/production/phase-0-ebook-production-draft.pdf`

## Differences from the prototype

| Prototype | Production |
|---|---|
| 9 sample pages | 18 pages with full learner content |
| Placeholder exercises | Real exercises for all 9 fragments |
| Generic page-number labels | True sequential page numbers |
| Internal `.prototype-label` badges | Removed entirely |
| Single ATY song | All 3 songs (ATY, SLY, TR) |

## Content source

All learner-facing content is derived from:

```
docs/content/PHASE_0_EBOOK_FINAL_CONTENT.md
```

The HTML must not contain internal editorial notes, review scores, production
status blocks, or publication blockers from that document.

## What must NOT appear in the PDF

- `[DESIGN: ...]` annotations
- Internal production status text
- Internal publication blockers
- Review scores or confidence percentages
- Pending placeholder text
- Any full lyric reproduction beyond the approved educational fragments

## Legal constraints

- Only the 9 approved educational fragments (ATY-01/02/03, SLY-01/02/03, TR-01/02/03) appear.
- No full verses, choruses, or surrounding lyrics are included.
- This guide does not replace official lyrics services or audio platforms.
- Official YouTube links are provided for listening only.
