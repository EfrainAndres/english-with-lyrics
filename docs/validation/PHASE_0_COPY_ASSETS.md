# Phase 0 Copy Assets

## Usage Notes

Use these Spanish copy blocks to promote the Phase 0 landing, free guide, survey, and first group interest list.

Rules:

- Use Sing Pronounce Repeat as the main public brand.
- Use English with Lyrics as the secondary/channel brand.
- Use Escríbelo como suena as the method.
- Do not mention personal names in public-facing copy.
- Do not promise instant fluency.
- Do not describe the product as a full-lyrics, translation, or karaoke replacement.
